Hardware & compatibility

Built to run lean.

Optimised for low-memory Raspberry Pis, without the overhead of a browser or desktop environment.

Supported hardware

Pi 3, 4 and 5
Memory
Optimised for 1GB devices
Displays

Requirements An existing Roon Server and active Roon subscription. Roon Bridge is optional if you also want to use the Pi as an audio endpoint.

Open source

Built on great foundations.

RoonDeck uses Roon’s official API for playback and library control. Experimental discovery features build on the reverse-engineering work of Arthur Soares.

Built with Alpine Linux, GTK4, Cage and the wider Raspberry Pi community.

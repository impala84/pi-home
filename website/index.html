Hardware & compatibility

Built to run lean.

Optimised for low-memory Raspberry Pis, RoonDeck delivers a responsive touchscreen experience without the overhead of a browser or desktop environment. No need to pay a premium for RAM you don’t need.

Supported hardware

Raspberry Pi
Pi 3, 4 and 5
Memory
Optimised for 1GB devices
Displays
Official 7″ V1, 7″ V2 and 10″ V2
5″ displays
Expected to work; untested and may feel cramped
Orientation
Portrait and landscape
Resolution
Responsive layouts for supported displays

Under the hood

Operating system
Alpine Linux (recommended)
Alternative OS
Raspberry Pi OS
Interface
Native GTK4
Display server
Cage / Wayland
Updates
Built-in Stable / Beta channels
Optional services
Roon Bridge and Netdata

Lightweight by design. Alpine Linux, native GTK4 and a minimal Wayland session keep memory consumption and background processes to a minimum.

Get RoonDeck

Ready to give it a spin?

Download the latest release, follow the installation guide and turn your Raspberry Pi into a dedicated Roon touchscreen.

View releases Installation guide

Requirements RoonDeck requires an existing Roon Server and active Roon subscription. Roon Bridge is optional if you’d also like to use your Raspberry Pi as an audio endpoint.

Open source

Built on great foundations.

RoonDeck is an independent, open-source project built using Roon’s official API, Alpine Linux, GTK4 and the work of the wider developer community.

Additional music discovery features build on research by Arthur Soares.

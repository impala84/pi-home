Experimental Roon integration

Powerful, actively maintained—and subject to change.

Some of RoonDeck’s library and discovery features use a reverse-engineered internal Roon interface. It is not a stable public API, so a future Roon update may break those features without warning. I use RoonDeck every day and intend to keep it working and updated, but compatibility cannot be guaranteed.

Get started

From download to music.

Five straightforward steps take RoonDeck from an image file to a dedicated music touchscreen.

Stable image v1.1.1One flashable Alpine ARM64 image for Raspberry Pi 3, 4 and 5. Pi 4 or newer recommended.
Download ↓
  1. 01

    Download

    Download the stable compressed RoonDeck ARM64 image for Raspberry Pi 3, 4 or 5.

  2. 02

    Flash

    Open Raspberry Pi Imager, choose Use custom, select the .img.gz file and write it to your microSD card.

  3. 03

    Connect

    Insert the card, connect the official touchscreen and network, then apply power. Leave the first boot running while RoonDeck prepares the card.

  4. 04

    Configure

    Choose the display and orientation, connect Wi-Fi if needed, set the timezone and optionally install Roon Bridge or Netdata.

  5. 05

    Enjoy

    Enable RoonDeck in Roon Settings → Extensions, choose the zone you want to control and start browsing.

Technical details and first boot

Use the official power supply for your Pi model. Ethernet is easiest for first setup, although Wi-Fi can be configured on the touchscreen. Raspberry Pi Imager can decompress the image while writing it.

After setup, open RoonDeck Settings → System → Software to install newer stable application updates when available.

Troubleshooting and advanced options

No controller in Roon?

Confirm the Pi and Roon Server are on the same local network, then check Roon Settings → Extensions.

Display or touch rotated?

Select the exact display model and orientation in RoonDeck Settings, apply the change and reboot.

Want a RAAT endpoint?

Enable Roon Bridge in RoonDeck Settings, then enable the Pi output separately in Roon Settings → Audio.

Need help?

Capture the display from web Settings and include it when opening a GitHub issue.

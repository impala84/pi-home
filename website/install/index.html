Required hardware

Choose the setup that suits you.

Minimum

Raspberry Pi 3 with 1GB RAM

Official 7-inch Raspberry Pi Touch Display V1, 16GB microSD card, correct official power supply and Ethernet or Wi-Fi. Designed for the core RoonDeck experience on low-powered hardware.

Recommended

Raspberry Pi 5 with 2GB+ RAM

Official 10-inch Touch Display 2, 32GB+ high-quality microSD card, official Pi 5 power supply and Ethernet. This matches the current ready-to-flash public image.

Display

Official Raspberry Pi Touch Display V1 is supported; Touch Display 2, 7-inch or larger, is recommended. Both portrait and landscape layouts are supported.

Storage

A reliable 16GB microSD card will work. Use 32GB or larger where available.

Power

Use the official power supply for your Pi model. Undersized supplies can cause instability during installation and updates.

Network

Ethernet is easiest for first setup. Wi-Fi can also be configured from the touchscreen onboarding flow.

Optional RAAT audio

Install Roon Bridge during onboarding to turn the Pi into a RAAT endpoint that appears under Roon Settings → Audio. Add a compatible DAC if you want analogue or digital audio output.

Useful extras

A case or display stand, a spare computer for writing the card, and temporary Ethernet access make setup easier.

Installation

From download to music.

  1. 01

    Download the Alpine image

    The current ready-to-flash image is for Raspberry Pi 5. Download the compressed image and its checksum from the stable release.

    Download the Pi 5 image
  2. 02

    Write the image to microSD

    Open Raspberry Pi Imager, choose Use custom, select the downloaded .img.gz file, choose the correct card and write it. Raspberry Pi Imager can decompress it directly.

  3. 03

    Connect and start

    Fit the microSD card, connect the official touchscreen and network, then apply power. Leave the first boot running while RoonDeck expands storage and starts the setup assistant.

  4. 04

    Complete touchscreen setup

    Choose the display profile and orientation, connect Wi-Fi if needed, set the timezone, create the device account and decide whether to install Roon Bridge or Netdata.

  5. 05

    Authorise RoonDeck

    In Roon, open Settings → Extensions and enable the RoonDeck controller. Return to the touchscreen and select the Roon zone you want to control.

  6. 06

    Update to the latest Stable release

    Open RoonDeck Settings, choose System → Software, keep the Stable channel selected and install the available update. Reboot when the screen asks you to apply a display or touch correction.

After installation

Useful first checks.

No controller in Roon?

Confirm the Pi and Roon Server are on the same local network, then check Roon Settings → Extensions again.

Display or touch rotated?

Select the exact display model and orientation in RoonDeck Settings, apply the display change and reboot.

Want a RAAT endpoint?

Enable Roon Bridge in RoonDeck Settings, then enable the Pi’s output separately in Roon Settings → Audio.

Need help?

Capture the display from web Settings and include it when opening a GitHub issue.

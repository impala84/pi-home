Netdata

Checking…
Controls the existing Netdata Agent and its boot state.
Collects metrics every 3 seconds and disables ML anomaly detection and netflow, otel, scripts.d, nfacct, network-viewer and debugfs. Keeps apps and go.d enabled. Alerts, dashboard and Cloud remain available; RAM savings vary. Turning off restores 1-second sampling, automatic ML and original plugin settings.

New installations download the latest official stable Agent, never Alpine’s older package. Netdata’s own daily updater maintains it; Pi Home updates preserve its installation and configuration.

Open Netdata

In Netdata Cloud, choose Add nodes, select Linux, and copy the complete installation command. Pi Home installs curl when needed, downloads Netdata’s official installer and supplies the validated Cloud settings from that command.

The pasted shell is never executed, logged or stored. Pi Home accepts only Netdata’s official address and passes the validated token, Room ID and Cloud address to a freshly downloaded official installer.
Cloud status is read from the local Agent.
